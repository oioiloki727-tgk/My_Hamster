# 🐹 Мой хомячок

Браузерная игра про уход за хомяком: монеты, уровни, скины, игрушки и перерождение.
К игре подключены регистрация по почте и облачные сохранения.

Без внешних зависимостей: `npm install` не нужен. Требуется **Node.js 18+**.

## Запуск

```bash
git clone <адрес-вашего-репозитория>
cd <папка>
node server.js
```

Откройте http://localhost:3000.

Пока почта не настроена, письма не отправляются: ссылка подтверждения печатается в консоль сервера.

## Настройка почты

Скопируйте `.env.example` в `.env` и заполните один из вариантов.

- **Resend:** `RESEND_API_KEY` и `MAIL_FROM` с адресом на вашем подтверждённом домене.
- **SMTP** (Gmail, Yandex, Mail.ru, Mailgun…): `SMTP_HOST`, `SMTP_PORT` (465 или 587), `SMTP_USER`, `SMTP_PASS`.
  Для Gmail нужен «пароль приложения».

Файл `.env` в `.gitignore`: не загружайте его на GitHub, в нём пароли.

## Публикация

На **GitHub Pages** сайт работать не будет: он показывает только статичные файлы, а регистрации нужен сервер.
Репозиторий можно подключить к хостингу с Node.js (Render, Railway, Fly.io, VPS):

- команда запуска: `node server.js`;
- переменные из `.env` задайте в настройках хостинга;
- `BASE_URL` — адрес сайта с `https://` (попадает в ссылку из письма);
- `TRUST_PROXY=1`, если перед сервером стоит прокси;
- к папке `data/` подключите постоянный диск, иначе аккаунты пропадут при перезапуске
  (путь меняется через `DATA_DIR`).

Файл `public/index.html` можно открыть и отдельно, но тогда игра работает как гостевая: без входа и синхронизации.

## Как это устроено

- Пароли хранятся только в виде хэша (scrypt), сессии — в httpOnly-cookie на 30 дней.
- Вход возможен только после подтверждения почты. Ссылка действует 24 часа.
- Неподтверждённые аккаунты удаляются через 3 дня.
- Есть лимиты на число попыток входа и регистрации и защита от CSRF.
- Гость может играть без аккаунта: его прогресс переносится в новый аккаунт при первом входе.

## Ограничения

- Игра работает в браузере, поэтому монеты технически можно подделать: сервер проверяет формат данных, а не честность прогресса.
- Восстановления пароля пока нет.

## Структура

```
server.js        сервер: регистрация, вход, сохранения
lib/mail.js      отправка писем (Resend / SMTP / консоль)
public/index.html  игра
.env.example     образец настроек
```
